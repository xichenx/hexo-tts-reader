# Project identity

**Your blog, out loud.**

Three paragraph lines become one flowing sound wave. The mark represents
blog text turning into speech, with a continuous stroke that suggests the
rhythm of narration. A blue-violet-to-cyan accent connects it to the reader UI.
The wordmark emphasizes **tts**, while the descriptor makes the Hexo context
explicit. The package and repository name remains `hexo-tts-reader`.

## Usage

Use the complete symbol, wordmark, and tagline in README headers. The README
`picture` element selects the light or dark export to match the reader's theme.
Use the symbol alone in browser tabs and compact UI. Leave clear space around
the mark rather than putting it inside another app tile.

Both the player preview and the example article reference the exported favicon.
The actual playback controls retain their existing functional icons.

## GitHub social preview

Upload `social-preview.png` in the repository's **Settings → General → Social
preview → Edit → Upload an image**. Committing the file does not change this
account setting. See [GitHub's instructions](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

## Editable sources

The current mark is native SVG; typography and composition are editable HTML/CSS.
PNG exports are rendered from those sources. The earlier imagegen concepts have
been superseded by this identity.
